# 我的世界生存服务器搭建：不用敲命令行，从配置选型到一键开服搞定朋友联机服

搜“我的世界生存服务器搭建”的人，需求其实分成两拨。一拨只是想让三五个朋友进同一个世界，晚上一起挖矿盖房；另一拨想长期开着，慢慢长成几十人的社区服。这两件事花钱的差法差很远，先想清楚自己属于哪一拨，后面的配置就不容易买错。

另外先说一句省事的话：现成的面板服已经能把「装 Java、下核心、放行端口、后台保活」这几步全省掉。如果你的目标是尽快和朋友玩上，没必要一上来就啃命令行。

## 一、配置怎么定：人数、玩法、在线时长

多数新手卡在第一步——不知道买多大。判断顺序其实只有三件事。

内存是第一瓶颈。大致账是这样：服务端本体吃 1～1.5GB，每个在线玩家再吃 200～400MB，每装一个模组再叠 50～200MB。世界探索范围越大，内存占用越高。所以 2GB 内存能开服，但基本只够两三个人安安静静地生存。

CPU 看单核，不看核数。Minecraft 的世界主逻辑跑在单线程里，一颗高主频的四核，实际表现往往好过核心数多但频率低得多的配置。这也是为什么老 E5 开 1.18 以上版本会明显吃力。

带宽最后考虑。生存服的网络流量不大，10M 上行带十来个人很轻松。真要卡，多半是内存或单核先顶不住。1.18 之后的版本对单核的消耗大约是 1.16 的两倍、1.12.2 的三倍，版本越高越吃配置。

| 玩法 | 人数 | 参考配置 | 给 MC 分配的内存 |
| --- | --- | --- | --- |
| 原版生存 / Paper 纯净服 | 2～5 人 | 2 核 4G | 2～3G |
| 加少量插件 | 6～10 人 | 4 核 8G | 5～6G |
| 中型整合包（30～80 模组） | 3～5 人 | 4 核 8G 起 | 6G 左右 |
| 大型整合包（80+ 模组） | 5～10 人 | 6 核 12G 起 | 10G 以上 |

## 二、生存服该用哪种服务端

原版官方服务端兼容性最好，但没插件、性能一般，纯生存其实不划算。

**Paper** 是目前纯生存最省心的选择。它在原版基础上做了大量性能优化，同时兼容 Bukkit/Spigot 插件生态，先用 Paper 开服，后面想加个领地保护、经济系统都还有路可走。

**Fabric** 适合轻量模组，启动快、新版本跟得紧。**Forge** 是大型整合包的标准，你要开 ATM 这类包基本绕不开它。**Purpur** 基于 Paper，可定制项更多。

有个容易被忽略的坑：基岩版和 Java 版是两套东西，端口也不同（Java 版默认 25565/TCP，基岩版 19132/UDP），手机、主机端的玩家进不了 Java 服，这一点开服前就要确认好。

## 三、Java 版本别装错

这是新手最常见的启动失败原因，装错版本服务端直接起不来：

| MC 版本 | 需要的 Java |
| --- | --- |
| 1.16 及以下 | Java 8 |
| 1.17 ～ 1.20.4 | Java 17 |
| 1.20.5 及以上 | Java 21 |

如果你打算玩某个整合包，先确认它锁定的游戏版本，再倒推 Java 版本。用面板服的话这一步基本不用管，平台会把环境配好。

## 四、两条路：面板一键开服，还是自己租 VPS 搭

|  | 面板服（一键开服） | 游戏云 VPS |
| --- | --- | --- |
| 操作方式 | 全程网页，选版本点一下就能开 | SSH 登录，自己装 Java、下核心、配 systemd |
| 环境 | 平台预装好 Java、MySQL、备份 | 需要自己维护 |
| 自由度 | 单端为主，能传整合包和自定义启动命令 | root 权限，一台机上多开、装任意程序 |
| 适合谁 | 想尽快玩上的人 | 想长期折腾、多服联动的人 |

新手建议从面板服起步。真到了需要多开、需要自定义系统组件的阶段，再切 VPS 也不迟——很多平台支持随时升配甚至换机型。

## 五、拿雨云举个例子：游戏云实际提供什么

雨云成立于 2018 年，是国内做云计算的厂商，产品线包括云服务器、裸金属、游戏云、对象存储等。它的游戏云分三类：**雨云面板**、**MCSM 面板**、**游戏云 VPS**。

其中雨云面板是自研的高可用面板，跑在 K8s 集群上，支持一键开服、CPU 升降级、可视化管理、备份和 MySQL。Minecraft Java 版可选的服务端覆盖官方原版、Paper、Purpur、Spigot、Pufferfish、Leaves、Leaf、Folia、Forge、NeoForge、Mohist、CatServer、ArclightForge、Thermos、Uranium、SpongeForge、Fabric、BungeeCore、Velocity、Waterfall 等，游戏版本从 1.8.8 一直到最新；基岩版则有 BDS、Nukkit、LeviLamina。面板还带在线文件管理、SFTP、备份还原和计划任务——定时备份这类生存服刚需，不用自己写脚本。

计费上分**固定计费**和**动态计费**两种。固定计费就是传统月租，跑多久都一样；动态计费是低价基础月租加每天按 CPU 超额使用量结算，闲置时省钱。判断标准很直接：每天都玩两小时以上，选固定；碎片时间偶尔玩，选动态。

## 六、从下单到朋友进服，实际是这七步

1. 注册账号，绑定微信后领首月 5 折券。
2. 进控制台 → 游戏云 → 购买游戏云，服务器类型选**雨云面板**。
3. 游戏类型选 Minecraft Java 版，服务端类型按需求选（纯生存直接选 Paper）。
4. 选机型、配置和购买时长，顺便决定固定计费还是动态计费。
5. 购买时会弹窗问**在线模式还是离线模式**：有正版账号选在线模式，没有就选离线模式；这个选项后期还能在文件管理里改配置文件。
6. 进面板后看终端，出现 `Done` 就说明开起来了。端口在 NAT 端口映射里看，服务端默认 25565，面板会给一个“对外地址:端口”。
7. 游戏里点多人游戏 → 添加服务器，地址填上一步那个“域名:端口”，进服后在终端输入 `op 你的游戏ID` 给自己服主权限。

全程不需要打开 SSH 客户端，也不需要手动装 Java——雨云面板会根据你选的服务端自动匹配对应版本。

## 七、生存服必须改的几个设置

**白名单**。生存服最该开的功能。`white-list=true` 之后，只有你添加过的 ID 才能进服，能挡掉绝大多数陌生人和破坏者。

**正版验证**。`online-mode=true` 时只允许正版账号进服，安全性更高。改成本就要做好被冒名顶替的准备。

**视距**。`view-distance` 从默认的 10 调到 8、`simulation-distance` 调到 6，是缓解 TPS 下降最直接的两个开关，代价只是看得稍近一点。

**游戏模式**。`gamemode=survival`、`difficulty=normal`，再用 `max-players` 限制人数上限。

**定时备份**。面板自带备份功能，设成每天凌晨跑一次、保留最近 7 天。存档丢过的人都懂这一步不能省。

## 八、几个大概率会踩的坑

**朋友连不上。** 先测端口：确认 NAT 映射里的外部端口和服务端配置里的端口一致。Java 版走 TCP，别按 UDP 去放行。再看双方版本是否完全匹配，“Outdated server”就是典型的版本不一致。

**四五个人就开始卡。** 优先加内存，而不是换 CPU。内存不够时服务端会频繁 GC，TPS 掉得比 CPU 瓶颈早得多。

**装完模组直接崩服。** 大概率是把客户端的优化模组也一起扔进服务端 `mods` 文件夹了。本地先跑通再上传，能省掉大量排查时间。

**1.18 以上版本用老旧机器开。** 单核性能不足时，人会感觉操作有延迟、方块掉落异常，这类问题不是靠加带宽能解决的。

## 九、怎么花这笔钱更合理

5 个人以内的纯生存，2 核 4G 加 Paper 就够，别一上来就买高配——多出来的是你暂时用不到的内存和带宽。10 到 20 人的插件服上 4 核 8G，大型整合包再考虑 6 核 12G 以上。

省钱的关键在计费模式，而不是死磕配置。只在周末开黑的固定小圈子，动态计费明显划算；天天有人在线的服，固定计费的月租更有性价比。

买之前不妨先花 1 元试用一天，或者干脆先用最低档开起来，感觉卡了在面板里直接升配——雨云支持弹性变配，不用重新搭一遍环境。
